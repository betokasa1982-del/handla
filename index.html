    Two phones, one list. Changes merge per item, so you can both add things at the same time without overwriting each other. Whoever edited an item last wins for that item only.
    The token lives only in this browser and is never written into the list itself. Give it the gist scope and nothing else — that way it can reach this one list and nothing else in your account. Setup steps are in the README.
